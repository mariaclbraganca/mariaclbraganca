🚀 Meu projeto: CodniKids
No 1º período do curso, comecei a desenvolver o CodniKids, um projeto integrador com o objetivo de criar uma plataforma multi-telas voltada para a educação infantil. A ideia é utilizar a IA para personalizar o aprendizado, com atividades lúdicas e interativas, ajudando todas as crianças, e principalmente aquelas neuroatípicas, a desenvolverem habilidades de lógica e programação de forma divertida, facilitando a sua integração no ambiente escolar.

Atualmente, sigo trabalhando nesse projeto, aprofundando os conceitos e transformando o rascunho inicial em uma plataforma robusta e funcional.
